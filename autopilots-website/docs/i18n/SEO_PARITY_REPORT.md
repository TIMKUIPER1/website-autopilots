# SEO parity report

Every indexable route has a self-canonical, localized metadata, the correct HTML language and a complete hreflang cluster for NL, EN, ES, DE, IT, FR and x-default. Non-indexable campaign and proposal routes keep `noindex` while still declaring canonical and alternates for parity control.

Sitemaps contain only indexable route families. The full audit fails on missing canonical, incorrect language or incomplete alternates.
