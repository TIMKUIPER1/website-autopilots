# Visual parity report

All locales render the same Astro components and CSS as Dutch. Translated content is data passed into those components, so grids, interactive demos, calculators, forms, accordions and responsive rules cannot drift into separate templates.

Automated DOM parity is clean. Desktop browser checks were completed on an industry page, knowledge library and interactive flow. Final release approval still requires a human visual pass at 375, 768, 1280 and 1440 pixels for text wrapping and typographic nuance.
