## Boundary

Signed-in browsers receive one bounded bootstrap contract and no direct table
surface. Session-context v2 selects one deterministic primary legal entity and
returns only brands inside that entity for which the current active profile has
an active exact or entity-wide membership. Session-context v1 is retired.

`authenticated` has no direct `SELECT` grant on the six governed schemas and
cannot call server-only helpers. The public v2 session RPC is the only
authenticated database RPC. It uses a fixed search path, validates
`auth.uid()`, returns contract `autopilots.session-context.v2`, and does not
write.
