## Boundary

Portfolio v2 is read-only. It derives launch progress from the latest governed
`software_launch_v1` run, onboarding steps and connector request statuses for
membership-scoped brands. It does not read raw product/customer data and does
not mutate onboarding evidence.

Each brand returns total/completed/attention/blocked steps, internal connector
approvals, approved intents, a progress percentage and the first unfinished
step. The top-level aggregate sums the same evidence. Both levels explicitly
keep provider authorization and external writes false. Progress is not a claim
of production readiness.
