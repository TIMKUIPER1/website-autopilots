## Boundary

`iam.app_sessions` stores a random application session's SHA-256 hash, profile,
Supabase user ID, assurance level, expiry and revocation state. It never stores
an access token, refresh token or raw cookie. RLS is enabled and there are no
policies or grants for `anon` or `authenticated`.

Three `security invoker` RPCs are executable only by `service_role`:

- create an MFA-satisfied session and append audit evidence;
- resolve a session while rechecking active profile, MFA and membership scope;
- revoke a session and append logout/revocation evidence.
