## Boundary

This change adds one organization-scoped read model for active profiles and
application-session evidence. Only a legal-entity-wide owner, admin or auditor
may request it through the server role. If a current session identifier is
supplied, it must be active and owned by the requesting profile.

The projection distinguishes MFA policy from actual session assurance. It
returns safe counts, AAL1/AAL2, validity and bounded timestamps only. Token
hashes, Auth user IDs and free revocation reasons are excluded. Browser roles
are revoked, generic session revocation is disabled, and no provider or
external write surface exists.
