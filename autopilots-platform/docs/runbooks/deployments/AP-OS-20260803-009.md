## Boundary

`public.autopilots_portfolio_snapshot(profile_id, legal_entity_id)` replaces
the managed portfolio's local fixture with a durable, organization-scoped
Supabase read. It requires an active profile and membership, applies optional
brand scope server-side, and exposes only governed legal-entity, brand,
connector and active-incident aggregates.

The contract deliberately returns `customerCount=0`, `goalCount=0` and
`financialQuality=unavailable` because no authoritative customer, goal or
reconciled financial projection exists in the control plane yet. It returns
`demoMode=false`, `sourceQuality=durable_control_plane` and
`externalWrites=false`. These fields distinguish missing business data from
synthetic demo data.

The function is executable only by `service_role`; anonymous and authenticated
browser roles are revoked. The runtime still supplies the current profile and
legal-entity IDs from its durable, MFA-gated application session.
