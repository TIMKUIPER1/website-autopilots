## Boundary

This immutable correction makes durable session restoration use the same
deterministic primary-organization selection as the authenticated login
bootstrap. Brand expansion occurs only through active memberships in that
single legal entity. The application validates the role, assurance level,
brand slug uniqueness and exact legal-entity ID again before accepting the
context.

For an active valid session, `last_seen_at` is updated at most once per five
minutes. Invalid, expired, revoked, suspended, MFA-insufficient or membership-
less sessions return no context and are never touched. The resolver remains
service-role-only and no provider or external write authority was added.
