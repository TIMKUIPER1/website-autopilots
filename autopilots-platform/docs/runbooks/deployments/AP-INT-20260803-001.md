## Boundary

`integration.onboarding_runs` and `integration.onboarding_steps` define one
repeatable six-step launch route per operating brand: foundation, website,
Supabase, product API, Stripe and monitoring. The registry stores status,
instructions, connector references and stable error codes; it stores no raw
provider credentials.

`public.autopilots_brand_onboarding(profile_id, slug)` is executable only by
`service_role` and rechecks an active profile plus current brand membership.
RLS remains enabled on both onboarding tables. The runtime exposes the result
only after resolving its own durable authenticated session.

A temporary MFA-satisfied owner session called the authenticated health route
for all four authorized brands. The raw session cookie was never printed or
written to disk and the session was revoked after the test.

| Brand | HTTP | Current status | Safe error code | Writes |

| RoofPlanner | 200 | unavailable | `ROOFPLANNER_API_UNREACHABLE` | false |

The scoped portfolio endpoint summarized the same observation as one healthy,
one degraded and two unavailable products. Anonymous portfolio access returned
HTTP 401.

Connector destination policy now rejects every remote HTTP endpoint and every
remote origin that does not exactly match the connector's separately configured
`*_ALLOWED_ORIGIN`. Loopback HTTP remains available for local product
development. Embedded URL credentials, query strings and fragments fail before
fetch; AutoReviews credentials are therefore never attached to a rejected
destination. Response bodies are capped at 100 KB and malformed JSON becomes a
stable contract error without exposing the endpoint or raw response.

An encoded path-traversal attempt returned HTTP 404. Replaying the test cookie
after revocation returned HTTP 401. The complete local release gate passed
68/68 automated tests.

## Recovery

This change adds isolated governed tables, a connector definition and
read-only registry data. It does not change the legacy product schemas. If the
runtime adapter causes an incident, stop `autopilots-platform`; product systems
and `sales-dashboard` remain independent. Database rollback requires a new
reviewed forward migration; do not drop the evidence tables destructively.
