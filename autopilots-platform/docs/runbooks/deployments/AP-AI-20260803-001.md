## Boundary

This change creates one operating-brand-scoped durable registry for bounded
agent facts: stable key, display name, purpose, version, lifecycle and observed
runtime status, risk ceiling, tool allowlist, budget limit and source quality.
No agent record is seeded or inferred from the legacy demo.

Runtime status cannot differ from `unknown` without an observation timestamp and
observed or reconciled source quality. Both `control_enabled` and
`external_writes_enabled` are constrained to false. There is no mutation RPC,
generic agent command, pause action or kill executor.
