# Safe error response

Use the versioned error runbook shown in the Autopilots Operations Inbox. First
confirm freshness and scope, then use only read-only health evidence. Never copy
credentials, private payloads or customer data into a task or incident.

The catalog provides diagnosis and escalation guidance only. It does not
authorize restarts, configuration changes, provider actions, notifications or
external writes. Those actions require their own typed workflow, current
context and risk-matched approval.
